The Big List Of Naughty Strings is a cool project. It contains a list of ‘interesting’ strings that you can use in your testing - thinkings like SQL injection, RTL text, zero-width characters, emoji, Zalgo text and more. The project can be found here:

https://github.com/minimaxir/big-list-of-naughty-strings

I thought it might be interesting to wrap these up in a WireMock extension that adds a naughtyString Handlebars helper, so templated responses can return strings from the BLNS. That extension can be found here:

https://github.com/leeturner/wiremock-blns-extension

As usual, I have added an example to my WireMock Docker example:

https://github.com/leeturner/wiremock-standalone-docker-example/blob/main/wiremock/mappings/blns.json

Take it for a spin and let me know what you think
