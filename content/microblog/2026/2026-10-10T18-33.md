Last week I put together a little Micronaut Framework WireMock extension to allow WireMock to be easily used inside tests.  It uses the same annotations as the WireMock spring boot extension.  At the moment it only supports http-based WireMock services but it does support the latest Micronaut and the latest WireMock OSS 4 beta so you get all the messaging and SSE support in there.

Along with that, I watched Faster Development with Java, Python, and Micronaut by Graeme Rocher and Thomas Wuerthinger from Devoxx Belgium.  I have never been much of a python dev but Pyronaut looks amazing and definitely worth a try. Link to the video below.

I decided to see if I could get my extension up and running on a Pyronaut Python application and other than a small class loader issue that needed fixing in my extension it all worked really well. Full end to end testing in Python, running on Pyronaut, using WireMock to mock out the upstream APIs. Very cool.

The latest version of the extension is up on maven central if you want to try it out.  Let me know what you think.
