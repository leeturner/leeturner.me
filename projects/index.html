Things I've built.

Here you can find a collection of side projects I have built for myself or others. Your mileage might vary, but you are welcome to dig in and have a play if they are useful to you.

kotlinmicronautcli

Micronaut Launch TUI

mtui is a terminal UI for creating Micronaut projects through Micronaut Launch, written in Kotlin and built with TamboUI. It puts the hundreds of available features in one searchable list, previews the generated files and unzips the project straight into the current directory. Inspired by Dan Vega's spring-initializr-tui.

kotlinmicronautwiremocktesting

wiremock-micronaut

Simplifies testing HTTP clients in Micronaut 5 and above. It starts WireMock servers per test class, binds their URLs into Micronaut configuration before your beans are created and injects them into your tests. The annotations mirror wiremock-spring-boot, so it should feel familiar.

wiremocktesting

wiremock-blns-extension

A WireMock extension that adds a naughtyString Handlebars helper, so templated responses can return strings from the Big List of Naughty Strings: SQL injection, RTL text, zero-width characters, emoji and more. Works with embedded WireMock and the standalone JAR or Docker image.

Xport

A command line tool written in Kotlin and Micronaut that converts an X/Twitter data export into Hugo markdown files, preserving the original timestamps and media. I used it to bring my old tweets over to the microblog on this site.

Conway's Game of Life

A terminal based Game of Life written in Kotlin using Micronaut and functional programming with Arrow. The universe wraps around like a torus and can be rendered in the terminal with ANSI colours or in a KorGE 2D window.

callback-logger

A simple Kotlin and Micronaut service that receives callbacks, useful when testing APIs locally that send them. It logs every POST or PUT it receives, has a simple web UI, and lets you define custom endpoints with your own response code and payload.
