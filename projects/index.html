A random stream of thoughts and software experiments

Here you can find a collection of side projects I have built for myself or others. Your mileage might vary, but you are welcome to dig in and have a play if they are useful to you.

Micronaut Launch TUI

mtui is a terminal UI for creating Micronaut projects through Micronaut Launch, written in Kotlin and built with TamboUI. The hardest part of creating a Micronaut project is finding the right features from the hundreds available, so mtui puts them all in one searchable list. Pick your options, preview the generated files and unzip the project straight into the current directory without ever leaving the terminal. It was inspired by Dan Vega’s spring-initializr-tui

View the project on GitHub

wiremock-micronaut

wiremock-micronaut simplifies testing HTTP clients in Micronaut 5 and above. It starts WireMock servers per test class, binds their URLs into Micronaut configuration before your beans are created and injects them into your tests. The annotations mirror wiremock-spring-boot so it should feel familiar if you have used that. It is available on Maven Central

View the project on GitHub

wiremock-blns-extension

wiremock-blns-extension is a WireMock extension that adds a naughtyString Handlebars helper, so templated responses can return strings from the Big List of Naughty Strings - SQL injection, RTL text, zero-width characters, emoji, Zalgo text and more. Every client test that hits the stub then exercises those cases for free. It works with both embedded WireMock and the standalone JAR / Docker image and is available on Maven Central

View the project on GitHub

Xport

Xport is a command line tool written in Kotlin and Micronaut that converts an X/Twitter data export into Hugo compatible markdown files, preserving the original timestamps and media. I used it to bring my old tweets over to my own microblog on this site

View the project on GitHub

Conway’s Game of Life

A terminal based implementation of Conway’s Game of Life written in Kotlin using Micronaut and functional programming with Arrow. The universe wraps around like a torus and can be rendered in the terminal with ANSI colours or in a KorGE 2D window

View the project on GitHub

Spektrum

Spektrum is a work in progress Sinclair ZX Spectrum emulator written in Kotlin and Micronaut, starting with an emulation of the Z80 CPU

View the project on GitHub

Micronaut CLI Template

Micronaut CLI Template is a ready to go Kotlin Micronaut command line application template with all the tooling I like already set up - a Gradle version catalogue, Kotlinter and Detekt for linting, Arrow for functional programming, Strikt for assertions and GitHub Actions and Dependabot for CI. Click “Use this template” on GitHub to start a new project from it

View the project on GitHub

callback-logger

callback-logger is a simple Kotlin and Micronaut service to receive callbacks, which is useful when testing APIs locally that send them. Point the API you are testing at it and it will log every POST or PUT it receives, with a simple web UI to see what has arrived. You can also define custom callback endpoints and configure the response code and payload it returns

View the project on GitHub

image-term

image-term is a terminal based image viewer written in V that renders images as colourful ASCII mosaics. It scales the image to fit your terminal, corrects for the aspect ratio of terminal characters and averages the colours within each block of pixels. It is based on the blog post Convert an Image into Colourful Ascii Art

View the project on GitHub

Hugo Progression Framework

Hugo Progression is a Hugo template that can render progression frameworks using the same data format as the Monzo progression framework - find out more information in this blog post

View the project on GitHub

BlinkyTapeTestWatcher

BlinkyTapeTestWatcher is a Kotlin based implementation of the Junit 5 TestWatcher API that hooks up your tests to a BlinkyTape LED strip - find out more information in this blog post

View the project on GitHub

pinboard2markdown

pinboard2markdown is a command line tool written in Kotlin and Spring Boot that communicates with the pinboard.in api to retrieve a selection of bookmarks that are tagged with a specified tag. It then converts those bookmarks to markdown and outputs them to the terminal.

Because I built this for myself it isn’t yet packaged up as a command line tool that can be easily downloaded and used. If you are a developer familiar with Kotlin or Java technologies that you can clone the github repo and build the project. If there is any interest I will release a formal version of the project and make it so it can be run just like any other command line tool.

I use this tool to build regular newsletters for the backend developers at Crunch and to generate my Geek Reads posts
